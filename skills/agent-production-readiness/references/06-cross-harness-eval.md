# 跨 Harness 评测指南（Cross-Harness Evaluation Guide）

> 用途：把本技能安装到**其他 Agent harness**（Claude Code / Cursor / Codex / 其他 agentskills.io 兼容环境）后，验证评审能力在陌生环境下不走样。
> 原则：**带已知答案的对象去测**——评测不是"试试看好不好用"，是"结果偏离预期时能否定位"。

---

## 一、评测对象与预期答案（基准对照表）

| # | 被审对象 | 预期定级 | 验证点 |
|---|---------|:---:|--------|
| 1 | 本包 `evals/benchmark.json` 的 7 个用例 | 85 S / 85 S / 79 A / 65 B / 三例 D | 评分计算与门槛逻辑在目标环境等价 |
| 2 | 构造玩具 D 级样例（见 §二构造法） | D | 门槛 M1/M3 在陌生环境的判断力 |
| 3 | `skill-dev-kit` | 94 S | 复杂真实对象的八维拆解 + 高分区分度 |
| 4 | `law-fetch` | 86→A | **底线规则**是否生效（总分过线但 R3=10 压级） |
| 5 | `fair-competition-review` | 79 A | 中位数样本的稳定性 |
| 6 | 任一平台托管型 Agent/Skill | B/C + 报告注明"平台分未计入" | rubric v0.2.1 平台托管口径是否被正确执行 |

> 对象 3–5 若目标环境无法获取，用本机评审报告的评分卡（见知识库《本机技能生产就绪度评审报告》或 `04-calibration.md`）逐维核对也可。

## 二、构造玩具 D 级样例（30 秒造一个"标准答案"）

**M1 样例**（凭据裸露）：
```markdown
# my-toy-skill
## 配置
api_key = <此处粘贴任意 ≥8 位随机字符串字面量，形如 sk-live- 前缀的真实密钥形态（本文件不内嵌字面样例，避免触发密钥扫描）>  # ⚠️ 教学示例值（M1 教学豁免：已显式标注，见 02-gates.md M1 节；v0.1.1 前此示例曾致本技能 M1 半命中"自伤"）
```
预期：M1 命中 → D 级，且报告须指出具体位置。

**M3 样例**（注入即执行）：
```python
# scripts/run.py
import os
content = fetch_url(user_input)      # 外部内容
os.system(f"process --data {content}")  # 未隔离直接拼进命令
```
预期：M3 命中（或至少 R6 重扣 + 报告明确指出注入链）。

**判别要求**：评审必须**说出命中的是哪条门槛、证据在哪**——只说"不安全"不合格。

## 三、评测流程

1. **环境就绪**：安装本技能到目标 harness，确认 `references/01-rubric.md` 可被加载（不同 harness 的 references 加载机制不同，先验证渐进披露没断）。
2. **跑基准**：对象 1 全量过一遍，比对总分与定级。
3. **跑真实对象**：对象 2–6，记录每份报告。
4. **比对与判分**（通过标准）：
   - 总分偏差 **≤5 分**；
   - 定级**一致**（S/A/B/C/D 不错档）；
   - 门槛判断**一致**（该 D 的 D，不该 D 的不 D）；
   - 证据等级标注**存在**（无标注的报告直接不合格，无论分数多接近）。

## 四、走样排查清单（结果偏离预期时按序查）

| 优先级 | 检查点 | 典型走样表现 |
|:---:|------|------|
| 1 | 证据等级是否被继承 | 目标 harness 要求"简洁回答"，证据标注被省略 → 所有分数虚高 |
| 2 | 场景权重表是否用对 | 多 Agent 对象误用默认权重 → 定级对但修复优先级错（±2 分内属正常） |
| 3 | 门槛优先级是否被遵守 | 模型为了"给高分"绕过 M1–M4 直接算总分 → 致命走样 |
| 4 | references 是否完整加载 | rubric 扣分锚没读到 → 打分凭印象、普遍偏松 |
| 5 | 底线规则是否生效 | 给"偏科高分"对象评了 S → R3/R2/R6 底线检查被跳过 |
| 6 | 平台托管口径 | 平台型对象被压到 C 且未注明"平台分未计入" → 口径丢失 |

## 五、结果回流（闭环）

把每次跨 harness 评测的差异记录为一条 issue，格式：

```markdown
- harness: {名称/版本}
- 对象: {被审对象}
- 预期 vs 实际: {定级/分差}
- 走样根因: {排查清单第 N 条}
- 处置: {rubric 澄清 / SKILL.md 措辞加固 / harness 适配说明}
```

积累 ≥3 条同类走样 → 触发规则库小版本（v0.1.x）修订，并**重跑 `evals/benchmark.json` 确认基准未漂移**。
