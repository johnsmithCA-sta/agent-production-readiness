## 风险分级口径

- 🔴 **关键**：上线即可能事故（数据泄露、资金损失、服务中断、违规发布）
- 🟠 **中危**：灰度期大概率暴露（错误率超标、成本失控、状态错乱）
- 🟡 **低危**：长期工程债务（可维护性、缺失回归）

## 报告质量自检（发出前过一遍）

- [ ] 结论在报告第一屏
- [ ] 每个评分都有证据级，无 C 级裸奔高分
- [ ] 门槛扫描四行齐全（通过也要列出）
- [ ] 风险按后果排序，不只按维度顺序
- [ ] 修复路径可执行（谁都能看懂下一步做什么）
- [ ] 免责声明在位
