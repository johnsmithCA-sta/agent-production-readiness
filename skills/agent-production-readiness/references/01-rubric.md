# 八维判定细则（rubric v0.2.2）

> 评审时逐维对照本表打分。**证据等级**：A=文件/产物可查（目录、脚本、配置、evals）；B=文档明确声明（SKILL.md/AGENTS.md 写明但未验证）；C=推断/口头。**C 级证据该维最高 60%**（score.py `--evidence` 强制）。
> 每维记录格式：`得分/满分 | 检查项达成 n/N | 命中锚 | 证据级 | 主要缺口`。

## 双轨评分规则（v0.2.2 起强制执行）

每维得分 = **基线分（检查项达成度）− 锚修正（命中的扣分锚）**：

1. **基线分** = 维度满分 ×（达成检查项数 / 检查项总数）。检查项达成 = 有 A/B 级证据支持；仅 C 级证据不算达成。基线分四舍五入取整。
2. **锚修正** = 逐项核对本维"扣分锚"，命中几条减几条；同一锚不重复扣。
3. 每维评审记录必须三行可复核：`检查项达成 n/N（逐项列编号）｜命中锚（逐项列）｜得分 = 基线 − 锚`。

**为什么双轨**（回应跨 harness 实测 P1-2"基线与锚不自洽"）：仅按"扣分锚"从满分起扣，未命中锚就保分——天然偏松，是"印象分"的制度根源。基线制要求**逐项挣分**，锚制负责**额外罚分**，两者互为约束，不同评审者的分差才能收敛。

**核算示范：R3 评估与测试闭环（16 分，5 检查项）**

某对象逐项判定：检查项1 eval suite（有 evals/ 用例集，A）达成；检查项2 触发词评估（无）未达成；检查项3 错误路径（2 条用例，A）达成；检查项4 失败案例回流（有声明无机制，B）达成；检查项5 换家族/独立上下文评审（自审自验）未达成。

基线 = 16 × 3/5 = 9.6 → 10；锚：命中"自审自验同模型同上下文 −3" → **R3 = 10 − 3 = 7**。记录：`3/5 达成(1,3,4)｜锚:自审−3｜R3=7/16`。

## R1 上下文与记忆管理（18）

**审什么**：长任务/多轮场景下，Agent 能否保持上下文质量，而非"窗口越大越变笨"。

**检查项**：
1. 是否有上下文压缩策略？机制是"先提取偏好/约束再总结"还是"直接摘要"（后者扣分，顺嘴约束会丢）。
2. 大工具输出是否卸载到文件、上下文只留摘要/首尾？
3. 子任务/探索是否用子 Agent 或隔离上下文（防主窗口被搜索噪声污染）？
4. 技能/工具描述是否渐进式披露（按命中加载，而非全量预载进系统提示）？
5. 是否有上下文预算意识（哪些信息该常驻、哪些按需取）？

**扣分锚**：
- 无任何上下文管理意识（全靠模型长窗口硬撑）→ **−8**
- 压缩策略会丢用户约束（直接摘要型）→ −5
- 无子任务隔离、主窗口堆满工具返回 → −4
- 描述全量预载、无披露分层 → −3

**典型证据**：A=存在 compaction hook/卸载脚本/子 Agent 设计文件；B=SKILL.md 声明策略；C=仅口头说明。

> **回流补充（一轮真实技能全量评审后）**：技能声明 Harness 能力由宿主平台承担（平台托管，如 ima 系列）时，相关检查项按 B 级证据计；报告必须注明"平台分未计入"，防止对平台技能的结构性误判。

## R2 工具与权限治理（16）

**审什么**：Agent 的工具使用是否"最小权限、危险有闸"。

**检查项**：
1. 是否声明权限档位（allow/ask/deny 或等价机制）？
2. 高风险/不可逆操作（资金/发布/删除/外发）是否强制 HITL 或守卫？
3. 资金/发布/外发路径是否独立加严（超时+幂等+回滚+防重复）？
4. 凭证是否走环境变量/密钥管理，而非硬编码？
5. 不可信代码是否在沙箱/隔离环境执行？

**扣分锚**：
- 高风险操作裸奔（无 HITL 无守卫）→ **触发 M2，判 D**
- 凭证硬编码 → **触发 M1，判 D**
- 无权限档位声明 → −5
- 无沙箱但操作均为本地只读 → −3
- 重试无退出条件（可能雪崩）→ −4

> **回流补充（一轮真实技能全量评审后）**：`[不可逆]标记 + 人工确认流程` 视为 ask 档等价物（skill-dev-kit / law-fetch 形态），不扣"无权限档位声明"的 −5。

## R3 评估与测试闭环（16）

**审什么**：Agent/Skill 凭什么知道自己改对了、没改坏。

**检查项**：
1. 有无自有 eval suite（用例集+期望输出，非一次性手动试）？
2. 触发词/触发场景是否经过系统评估（非拍脑袋写）？
3. 是否含**错误路径测试**（错误输入/异常场景必须被正确拦截或处理）？
4. 线上/实战失败案例是否回流进 eval（回归机制）？
5. 评审/验证环节是否换家族模型或独立上下文（防"AI 审 AI 互相点头"）？

**扣分锚**：
- 只测 happy path（无错误路径用例）→ **−8**
- 无任何 eval 产物 → −8
- 有 eval 但无回归（改完不跑）→ −4
- 自审自验同模型同上下文 → −3

**说明**：四样本回测显示 R3 是最大区分维度（强样本 15、中样本 11、平台 Agent 8），评 S 需 ≥12。

## R4 状态与持久化（10）

**审什么**：中断/崩溃/超长任务下，工作能否接续。

**检查项**：
1. 长任务是否有 checkpoint / 断点续跑设计？
2. 共享状态是否单点写入 + 只读分发（多写是腐烂之源）？
3. 多 Agent 并行是否有工作隔离（独立目录/worktree/锁）？
4. 进度是否显式落盘（非只存在对话上下文里）？

**扣分锚**：
- 会话崩溃全部重来（无持久化）→ −5
- 状态多处可写 → −4
- 无进度落盘 → −3

## R5 可观测性与复盘（10）

**审什么**：出问题能否定位、事后能否复盘、成本是否可见。

**检查项**：
1. 关键决策/工具调用是否留痕（可复盘谁做了什么、为什么）？
2. 是否有 token/成本统计与预算上限？
3. 是否有复盘模板/过程留痕机制（失败变资产）？

**扣分锚**：
- 黑盒运行、无任何留痕 → −6
- 无成本可视（烧多少不知道）→ −3
- 有日志但无决策记录（只有结果）→ −2

## R6 安全与风险控制（16）

**审什么**：面对注入、出错、失控时的拦截能力——**Harness 级，非提示词级**。

**检查项**：
1. 外部内容（检索结果/工具返回/用户上传文档/网页）是否与系统指令**数据/指令分离**？
2. 是否有 Harness 级防注入强制点（内容校验/隔离执行），而非仅靠系统提示"请小心"？
3. 工具失败是否有降级/退出策略（不盲目重试）？
4. 发布前是否经过脱敏/安全审查（自动扫描+专业审查）？
5. 危险动作是否有"决策与执行分离"（审的人不等于干的人）？

**扣分锚**：
- 外部内容可直接当指令执行 → **触发 M3，判 D**
- 只有提示词级防护（无工程强制点）→ −6
- 工具失败盲目重试无退出 → −4
- 无脱敏审查 → −4（若含敏感域则触发 M1）

## R7 成本治理（8）

**审什么**：token 与调用成本是否可估、可控。

**检查项**：
1. 是否估算单次调用 token 量级并设预算？
2. 有无降本设计（共享证据包/按需读取/缓存友好/拼图压读图次数）？
3. 多 Agent 场景是否标注成本放大（~15×）并有对策？

**扣分锚**：
- 无成本意识 → −5
- 多 Agent 无共享状态/证据包设计（重复读图×N）→ −3
- 无预算上限 → −2

## R8 工程可维护性（6）

**审什么**：经验是否沉淀为资产、版本是否可治理、组件是否会腐烂。

**检查项**：
1. 规则/经验是否沉淀为 AGENTS.md/记忆文件/Changelog（每次犯错变成投资）？
2. 是否有版本治理（版本号、变更记录、tag 一致）？
3. 是否定期验证并删除失效 Harness 组件（"为删除而构建"）？

**扣分锚**：
- 经验全在人脑、无任何沉淀 → −3
- 无版本治理 → −2
- 从未清理失效组件 → −1

## §9 双场景权重表

| 维度 | 默认 | 场景A 单 Agent 工具型 | 场景B 多 Agent 编排型 |
|------|:---:|:-:|:-:|
| R1 上下文 | 18 | 20 | 16 |
| R2 权限 | 16 | 20 | 12 |
| R3 评估 | 16 | 16 | 16 |
| R4 状态 | 10 | 6 | 16 |
| R5 可观测 | 10 | 8 | 12 |
| R6 安全 | 16 | 18 | 14 |
| R7 成本 | 8 | 6 | 10 |
| R8 可维护 | 6 | 6 | 4 |
| **合计** | 100 | 100 | 100 |

**场景判定指引**：
- 场景A：单 Agent + 工具调用为主（评审技能、生成技能、爬虫、转换工具）。
- 场景B：显式多 Agent 编排（orchestrator-worker / 扇出扇入 / 共享状态 / 图拓扑）。
- 双场景不改变定级（校准结论：影响 ≤±2 分），影响的是**修复优先级排序**（场景B 先修状态与可观测）。

## 关键维度底线规则（评 S 必要条件）

**S 级要求**：总分 ≥85，无 🔴 项，且 **R1≥11/18 且 R2≥12/16 且 R3≥12/16 且 R6≥12/16**。
任一关键维度不达标 → 最高 A 级（防止靠其他维度拉分的偏科高分）。

## 定级标准

| 等级 | 条件 | 含义 |
|------|------|------|
| S | ≥85 + 底线规则 + 无 🔴 | 可无人值守上生产 |
| A | 75–84，无 🔴 | 基本就绪，灰度+人工抽查 |
| B | 60–74 | 部分就绪，修复 🟠 后复评 |
| C | <60 | 未就绪，系统性补课 |
| D | 命中 M1–M4 任一 | **禁止上生产** |
